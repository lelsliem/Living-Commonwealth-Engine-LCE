Glossary



Adapter

Platform-specific implementation.



Core

Platform-independent engine.



Entity

Abstract simulation object.



Event

A notification published through the Event Bus.



Module

A dynamically loaded extension.



Platform

A supported game implementation.



Registry

Stores engine services.



Service

A globally available engine system.



Simulation

Systems that create emergent behaviour.



SDK

Public API for developers.



Subsystem

A major engine component.



Runtime

The systems active while the engine is running.
