Development Charter



Every public class shall have:



• Header

• Source

• Documentation



Every public function shall be documented.



Every commit shall compile.



Every release shall build cleanly.



Warnings are treated as problems.



Core never includes platform-specific headers.



Platform code lives inside platform modules.



Documentation is maintained alongside code.



New features require documented design.



Architecture changes require discussion and agreement.



Quality is always preferred over speed.



The engine is built for long-term maintainability.



Teach through code.



Major architectural decisions require agreement from both project leads.



General people don't care or understand it. Developers do



Every public function should be understandable by reading its declaration and accompanying comment alone.
