The engine surface is unchanged from 0.9.1 — the API freeze holds,
32/32 suites green. 1.0.0 is the promise made good: the engine, the
SDK, the docs, and The Living Commonwealth — live in Fallout 4 —
released together.

## The engine

- The API freeze, in force since 0.8.4, holds through 1.0.0 —
  SurfaceTest pins every public enum ordinal, struct field type, and
  function signature.
- All seven mod types provably possible as patterns in the samples:
  Economy, Legacy, Weather, Children, Faction Wars, Disease, Roads.
- 32/32 suites green on four platforms (Windows MSVC, Ubuntu GCC,
  Ubuntu Clang, macOS Clang) in Debug and Release; CodeQL clean.
