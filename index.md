# Living Commonwealth Engine (LCE)

**Building living worlds through simulation.**

LCE is middleware — a simulation engine that brings persistent life,
memory, relationships, and emergent behaviour to Bethesda Game Studios
titles. Instead of scripting every event, LCE **simulates** systems
from which events naturally emerge: entities with needs, memory that
fades, relationships that drift, and a deterministic, tunable,
saveable tick. The first platform is Fallout 4. The core never knows.
